# 硬件：接线与上电检查

适用：ESP32-PICO-V3-02 + ICS-43434
数据手册依据：`modules/ICS-43434.PDF`（InvenSense DS-000069 Rev 1.2）

---

## 1. 接线

```
        ICS-43434（顶视 / 焊盘朝下）              ESP32-PICO-V3-02
        ┌─────────────┐
        │ 1  WS   ●───┼───────────────────────────  GPIO 25
        │ 2  LR   ●───┼──────┐
        │ 3  GND  ●───┼───┬──┼───────────────────  GND
        │ 4  SCK  ●───┼───┼──┼───────────────────  GPIO 26
        │ 5  VDD  ●───┼─┐ │ │
        │ 6  SD   ●───┼─┼─┼─┼──┬────────────────  GPIO 22
        └─────────────┘ │ │ │  │
                        │ │ │  └──[ 100 kΩ ]──┐
                        │ │ │                 │
                      3V3 │ │                GND
                          │ │
                    [0.1 µF]│
                          │ │
                         GND│
                           GND  ← LR 直接接 GND（拉低 = 左声道）
```

> **引脚编号依据**：数据手册 Table 8「PIN FUNCTION DESCRIPTIONS」——
> 1=WS、2=LR、3=GND、4=SCK、5=VDD、6=SD。

### 接线要点

| 要点 | 为什么 |
|---|---|
| **LR 必须接 GND** | 拉低 → 数据出在**左声道**。我们只取左声道。悬空会导致输出声道不确定 |
| **SD 加 100 kΩ 下拉** | SD 是三态输出（手册 C4），右声道期间会进入高阻，不加下拉线会浮空 |
| **VDD 就近并 0.1 µF** | 手册明确要求。不加会导致电源噪声直接进 ADC |
| **WS/SCK/SD 尽量短** | 1.024 MHz 的时钟，长飞线会引入振铃。**杜邦线 ≤ 15 cm 为宜** |
| **不接 MCLK** | ICS-43434 不需要主时钟，它自己从 SCK 派生。ESP32 侧 `mclk = I2S_GPIO_UNUSED` |

### ⚠️ 你买的是模块，不是裸芯片 —— 按丝印名字接线

本项目实际使用的是**国产 ICS-43434 全向麦克风模块**，资料见
`modules/93545.pdf`。它与上面那张「裸芯片引脚编号图」有两点不同：

**① 模块上标的是功能名，不是 1–6 的脚号。**
→ **按名字接线**（WS / SCK / SD / L/R / VDD / GND），别去数第几个脚。

**② 模块上有一个 PS 跳线焊盘，用来选声道：**

| PS 焊盘短接 | 输出声道 |
|---|---|
| 左边 + 中间 | 右声道 |
| **右边 + 中间** | **左声道 ← 出厂默认** |

> ✅ **默认就是左声道**，与 `mic_test.c` 默认取的左声道一致，**不用改**。
>
> ⚠️ 但如果这个跳线被改过（或你买到的是改过的板子），数据会跑到右声道，
> 固件会读到**静音** —— 表现和"没接好"一模一样。

**好消息：不用焊板子也能解决。** 固件的 `rec` 命令会**同时报告两个声道**，
如果发现数据在另一路，直接敲 `chan 1` 即可，不用动硬件。

`rec` 的判读输出会明确告诉你属于哪种情况：

```
判读: ❌ 数据在【右声道】，当前取的却是【左声道】—— 声道选错了！
      软件修: 敲 `chan 1`
      硬件修: 模块 PS 跳线焊盘选错（见 docs/modules/93545.pdf）
```

### 关于板载元件

模块**已经板载了 0.1 µF 去耦**（PS 跳线也说明它是模块级产品）。
**先目视确认 SD 有没有下拉电阻**，有就不用再加了 —— 重复加不影响功能但白费事。

## 3. 上电前检查表

**通电前逐条勾掉**，这几条错了可能烧件：

- [ ] **VDD 接的是 3V3，不是 5V** —— ICS-43434 上限 3.63 V，接 5V 直接烧
- [ ] **VDD 和 GND 没有接反**（万用表通断档量一遍）
- [ ] LR 接在 GND 上（不是悬空）
- [ ] SD 的下拉电阻在 GND 侧（不是接到 3V3）
- [ ] 没有用到 GPIO 6–11（**这几个脚连着 SPI Flash，接任何东西都会死机**）

## 4. 上电后逐级验证

按顺序做，**每一步都可能暴露不同的问题**，跳步会让定位变难。

### 第 1 级：时钟对不对

用示波器或逻辑分析仪（没有的话跳过，靠第 2 级判断）：

| 测点 | 期望值 | 不对说明什么 |
|---|---|---|
| GPIO 26 (SCK) 频率 | **1.024 MHz** | 采样率配置错 |
| GPIO 25 (WS) 频率 | **16.000 kHz** | 采样率配置错 |
| **SCK ÷ WS** | **必须 = 64** | ❌ 若是 32 → **用了 `I2S_SLOT_MODE_MONO`**，见风险 R1 |

> **SCK ÷ WS = 64 是这一级唯一要看的数。** 数据手册要求「每 WS 帧正好 64 个
> SCK」，这个比值直接验证了帧长配置对不对。

### 第 2 级：数据合不合理

录 3 秒，打印原始 int16 样本的统计：

| 情况 | 表现 | 病因 |
|---|---|---|
| ✅ 正常 | 说话时峰值 **±1000 ~ ±8000**，静音时 |值| < 100 | —— |
| ❌ 恒为 0 | 全是 0 | 没接 SD / 声道选错（试改成取奇数下标） |
| ❌ 幅度极小 | 峰值几十 | 位移方向错了，试 `raw >> 8` |
| ❌ 满量程噪声 | 值在 ±32767 跳 | 位移过头，或 SCK 太快 |
| ❌ 规律的"嗡" | 周期性干扰 | 电源没去耦 / 线太长 |

### 第 3 级：听感

录 10 秒人声，PC 上播放。

**✅ 通过标准：能听清自己说了什么，没有明显电流声或断续。**

> 这一级是**阶段 1 的最终验收**。到这里为止，后面所有阶段都建立在它之上。

## 5. 常见故障对照

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 完全无数据 | SD 没接 / 麦克风没供电 | 量 VDD 是否 3.3 V |
| 有数据但是噪声 | **SCK/WS 用了 MONO**（帧长 32 而非 64） | 改成 `I2S_SLOT_MODE_STEREO` |
| 声音极小 | 24→16 bit 位移错 | 用 `raw >> 16` |
| 周期性咔哒声 | DMA 缓冲太小，欠载 | 增大 `dma_frame_num`（上限 511） |
| 音调偏高/偏低 | 采样率时钟不准 | 用 `I2S_CLK_SRC_APLL` |
| 录久了越来越偏 | 同上，时钟误差累积 | 同上 |
| 数据错位、字听不清 | WS 极性反了 | 试 `ws_pol = true` |
| 板子不断重启 | GPIO 6–11 被占用 | 立刻断开 |

## 6. 参考：ESP32-PICO-V3-02 上可用的 GPIO

| GPIO | 可用性 | 说明 |
|---|---|---|
| 0 | ⚠️ | strapping（启动模式），有 BOOT 键的话被占用 |
| 1 / 3 | ⚠️ | UART0 TX/RX —— **占了就看不到串口日志** |
| **2** | ⚠️ | strapping |
| 4, 5 | ✅ | 空闲 |
| **6 – 11** | ❌ | **SPI Flash，绝对不能用** |
| **12, 15** | ⚠️ | strapping（影响 Flash 电压 / 启动日志） |
| 13, 14 | ✅ | 空闲 |
| 16, 17 | ✅ | 空闲（PICO 封装上可能未引出） |
| 18 – 23 | ✅ | 空闲，本项目用 **22** |
| **25, 26** | ✅ | 本项目用（兼作 DAC，本项目不用 DAC） |
| **27** | ✅ | 推荐给阶段 6 的按键 |
| 32, 33 | ✅ | 空闲 |
| 34 – 39 | 输入专用 | 无内部上拉，只能做输入 |
