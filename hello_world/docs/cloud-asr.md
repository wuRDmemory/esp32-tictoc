# 附录：云 ASR 申请指引（备查）

> ⚠️ **你现在不需要看这个。**
>
> 本项目走**本地路线**（FunASR + ollama），**不需要申请任何 API key** ——
> 不注册、不实名、不充值、音频不出本机。
>
> 这份文档是为**将来**准备的：当你觉得本地识别率不够、或想在手机上用时，
> 直接照这里做即可。架构上已经留好了位置（`AsrProvider` 抽象，见 PRD D7）。

---

## 0. 什么时候才该考虑上云

| 该考虑上云 | 不该上云 |
|---|---|
| 本地识别率不满意，且换模型也救不回来 | 只是偶尔识别错 —— 先调静音阈值、换个 ASR 模型（见 `prd.md` D7.1） |
| 想在没有 GPU 的机器上跑 | 你的 4070 Ti Super 闲着 |
| 想支持方言 / 多语种 | 只讲普通话 |
| 需要说话人分离等高级功能 | 不需要 |
| 音频内容不敏感 | **音频敏感 / 涉密** |

> **最后一条最重要**：上云意味着**你的每一句话都会上传到第三方服务器**。
> 本地路线的核心价值就是没有这件事。

## 1. 阿里云 · 智能语音交互（ISI）

**国内最主流的选择，实时语音识别成熟。**

### 1.1 凭证：注意是**三个**，不是一个 API key

这是最容易搞混的地方。ISI 的鉴权是**三件套**：

| 凭证 | 从哪来 | 作用 |
|---|---|---|
| **AccessKey ID + Secret** | RAM 控制台 | 换取 Token 用 |
| **Appkey** | 控制台创建的项目 | 标识你的项目 |
| **Token** | 用 AccessKey 调 `CreateToken` 换取 | 实际请求的鉴权凭证，**会过期** |

> ⚠️ **Token 不会自动刷新**，官方文档明确要求应用自己定期刷新。这是接入时
> 最容易漏的一环 —— 表现为"跑了几小时突然开始报鉴权失败"。

### 1.2 开通流程（官方六步）

1. **注册 + 实名认证**阿里云账号
   - 多人协作建议创建 **RAM 用户**，用系统策略 `AliyunNLSFullAccess`
   - **不要日常用主账号的 AccessKey**，权限过大
2. **创建 AccessKey**（建议建在 RAM 用户下）
   - ⚠️ AccessKey Secret **只在创建时显示一次**，当场存好
3. **开通服务**：进智能语音交互控制台 → 产品开通页 → 选「免费试用版」或「商用版」→ 勾选条款 → 立即开通
   - ⚠️ 若你 2018-07-05 **之前**开通过 V1.0，用 V2.0 需**按指引重新开通**
4. **创建项目** → 拿到项目的 **Appkey**
5. **获取 Token**：测试阶段可在控制台取**临时 Token（有效期 24 小时）**，仅供测试；生产必须用 AccessKey 通过 SDK 自动获取
6. **集成**：WebSocket（`wss://`）流式上传音频

### 1.3 免费额度（截至 2026-09，以官网为准）

- 新用户部分服务有 **3 个月免费试用**，试用版最多 **2 路并发**
- 录音文件识别另有**每天 2 小时**免费额度
- 试用版下**麦克风不限量**（正好对应我们的场景）
- 商用版按量计费，资源包例如录音文件识别 40 小时档（¥100/年起）
- ⚠️ **不支持免费试用、仅商用版**的服务：长文本语音合成、流式文本语音合成
  CosyVoice、录音文件识别极速版/闲时版、VoiceChat。调用会返回错误码 `40000010`

### 1.4 另一条路线：百炼（DashScope）

比 ISI 简单，**只有一个 `sk-` 开头的统一 API Key**，LLM / ASR / TTS 共用一个：

- 实时 ASR 可调 `qwen3-asr-flash-realtime`
- VAD 模式（服务端自动断句）/ Manual 模式（客户端控制断句）可选
- **对个人开发者更友好** —— 如果你要上云，我建议**先试这条**

### 1.5 音频要求

与我们固件的输出**完全吻合**，不需要改动：

```
16 000 Hz · 16 bit · 单声道 PCM
```

## 2. 讯飞开放平台 · 实时语音转写

**中文识别老牌选择，开发者生态成熟。**

### 2.1 凭证：也是**三个**

| 凭证 | 说明 |
|---|---|
| **AppID** | 创建应用后自动生成 |
| **APIKey** | 同上 |
| **APISecret** | 同上，**尤其不要泄露** |

三者**缺一不可、每个应用独立生成、不能混用**。

### 2.2 申请流程

1. **注册 + 实名认证**（xfyun.cn）
   - ⚠️ 未实名**无法调用**，部分资料提示审核需 1–2 天
2. **控制台 → 创建应用**（填名称、分类、功能描述、应用平台）
3. **添加新服务** → 选「**实时语音转写**」
4. **拿凭证**：AppID / APIKey / APISecret
5. **领免费额度**：⚠️ 到**实时语音转写的产品页面**领取，不是在控制台首页。
   官方明确：测试或正式使用前需先去产品页获取免费额度或购买套餐，**否则调用失败**
6. **接入**：WebSocket（`wss`）长连接

### 2.3 音频要求

```
16 000 Hz · 16 bit · 单声道 PCM    ← 与我们固件一致
建议每 40 ms 发送 1280 字节          ← 我们的帧是 512 B / 16 ms，需重新切片
```

### 2.4 可选优化

控制台「实时语音转写 → 个性化热词」可上传热词（**约 1 小时后生效**），
对专有名词识别率提升明显。

## 4. 通用注意事项

| # | 事项 | 说明 |
|---|---|---|
| 1 | **实名认证是硬门槛** | 国内所有云 ASR 都要，且可能要等 1–2 天 |
| 2 | **Token / Secret 不要进 git** | 用 `.env` 或环境变量，`.gitignore` 里排除 |
| 3 | **免费额度会过期** | 到期后**先扣余额再失败**，留意余额 |
| 4 | **并发路数限制** | 免费版通常 2 路。我们单设备够用 |
| 5 | **音频会上传** | 敏感内容不要用云 |
| 6 | **按量计费** | 挂机会一直烧钱，务必加"无音频就断开"的逻辑 |
| 7 | **价格和额度会变** | 本文档的数据截至 2026-09，**以官网控制台为准** |
| 8 | **先跑通本地再上云** | 本地的 `AsrProvider` 接口是稳定的；先让它工作，云的实现照着接口填即可 |

## 5. 接进来要改什么（架构上已留好）

只需要**新增一个文件**，不动 `session.py`：

```python
# voice_notes/PC/asr/cloud_aliyun.py
from .base import AsrProvider

class CloudAliyunProvider(AsrProvider):
    def __init__(self, appkey, token): ...

    def transcribe(self, wav_path: str, on_progress=None) -> str:
        """把整段 WAV 上传，返回带标点的全文。

        注意：v1.1 起接口是"整段"而非"流式"（见 prd.md D12），
        所以这里用录音文件识别（一句话/录音文件）接口即可，
        不必接实时 WebSocket 接口 —— 后者复杂度高得多。
        """
        ...
```

> **v1.1 的一个附带好处**：改成整段转写后，云侧也**不必再用实时 WebSocket 接口**，
> 用更简单的"录音文件识别"即可。上面 §1.5 / §2.3 提到的实时接口约束
> （每 40ms 发 1280 字节之类）在这里都不用管了。

然后在 `config.toml` 里改一行：

```toml
[asr]
provider = "cloud_aliyun"    # 原来是 "funasr"
```

**这就是 `AsrProvider` 抽象存在的全部意义。**
